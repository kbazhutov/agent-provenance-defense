# Agent Provenance Defense

Курсовой проект о prompt injection в агентных системах.

## Идея

Пользователь просит агента изменить только открытые записи клиента Alpha. Агент читает документы и вызывает `update_record`. Вредоносный документ может попросить изменить другие записи или другое поле.

Сейчас в репозитории находится baseline без проверок. Следующим шагом добавим защиту и сравним её с baseline.

## Запуск

Нужен Python 3.10 или новее. Дополнительные пакеты не нужны.

```bash
python scripts/run_baseline.py
```

Команда пересоздаёт SQLite-базу в памяти для каждого сценария и сохраняет результаты в:

- `results/baseline.csv`
- `results/baseline.json`

## Папки

- `research_plan.md` — вопрос и план эксперимента.
- `data/` — схема базы и тестовые CSV-файлы.
- `src/agent/` — baseline.
- `src/environment/` — SQLite и инструмент записи.
- `scripts/` — команды запуска.
- `results/` — результаты последнего запуска.
